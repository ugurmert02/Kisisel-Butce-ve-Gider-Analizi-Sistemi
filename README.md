# Kişisel Bütçe ve Gider Analizi Sistemi

Python ile yazılmış, harcamaları kaydeden ve analiz eden bir bütçe asistanı.

## Özellikler
- Harcama ekleme (açıklama, tutar, kategori)
- CSV dosyasında kalıcı kayıt
- Toplam ve kategori bazlı harcama raporu
- Matplotlib ile pasta grafiği

## Kullanılan teknolojiler
Python, pandas, matplotlib

## Nasıl çalıştırılır
1. `pip install pandas matplotlib`
2. `python butce.py`
